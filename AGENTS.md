# Maintenance du pack

- Le dépôt est la source des plugins installés. Modifier ces fichiers, puis utiliser `scripts/Install.ps1`.
- Conserver Spotify.exe, Spotify.dll et chrome_elf.dll officiels et signés. Ne pas ajouter de patch binaire, d'exclusion antivirus ou de désactivation de protection.
- Sauvegarder avant de remplacer les plugins ; préserver les profils et les réglages utilisateur.
- Ne pas envoyer de jetons, cookies, profils, sauvegardes ou diagnostics sur GitHub.
- Garder les versions amont stables. Mettre à jour les versions prises en charge uniquement après vérification.
- Vérifier les erreurs de démarrage et les réponses des services ; distinguer un plugin installé d'une fonctionnalité vérifiée.
- Utiliser Computer Use seulement quand une vérification indispensable ne peut pas être effectuée autrement.
