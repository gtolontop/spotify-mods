# spotify-mods

Plugins Spicetify pour Spotify sous Windows.

Spotify **1.3.3.264** · Spicetify **2.45.3**

- `Repair.cmd` : installer ou réparer.
- `Update.cmd` : récupérer et installer la dernière version du dépôt.
- `F11` : plein écran.

Inclus : Adblockify, Spicy Lyrics, Lyrics Plus, Full App Display, Shuffle+, Loopy Loop, Oneko, Song Stats et Marketplace.

Les réglages sont sauvegardés localement avant chaque installation. Les exécutables Spotify restent inchangés.
